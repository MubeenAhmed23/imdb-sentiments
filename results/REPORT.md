# IMDb Movie Review Sentiment Analysis

## Abstract

This project builds and evaluates a supervised NLP system that classifies movie reviews as positive or negative. It uses the official Stanford IMDb Large Movie Review Dataset, a text-preprocessing and TF-IDF pipeline, and a linear Support Vector Machine (SVM). To examine the effect of data scale, the model was trained on stratified samples of 1,000, 5,000, and 25,000 reviews and evaluated on the same untouched 25,000-review test set. Accuracy increased from 83.38% to 88.93% as the training sample grew.

## 1. Problem and objective

Movie reviews provide a direct expression of audience opinion, but manually reading large collections is time-consuming. The objective is to develop a reproducible binary text classifier that accepts a review and predicts positive or negative sentiment. The project follows the selected movie-review task in the course brief and reports performance on a held-out test split.

## 2. Dataset

The Stanford IMDb Large Movie Review Dataset contains 50,000 labeled movie reviews divided into 25,000 training and 25,000 test reviews. Each split is balanced: 12,500 positive and 12,500 negative examples. The project uses this official split and does not move test examples into training. The loader reads the local extracted dataset, checks that all class folders contain the expected number of reviews, and verifies the archive's published MD5 checksum when downloading it.

## 3. Method

### 3.1 Preprocessing and representation

Reviews are lowercased and tokenized with a word-boundary regular expression. Common English stop words are removed, while negation cues such as “not,” “never,” and “no” are preserved because they can change sentiment. Remaining tokens are stemmed with NLTK's English Snowball stemmer. A TF-IDF vectorizer represents unigram and bigram features, uses sublinear term frequency, and caps the vocabulary at 200,000 features.

### 3.2 Classifier

A linear Support Vector Classifier (`LinearSVC`, C=1.0) is trained on the TF-IDF features. The vectorizer is part of the fitted scikit-learn pipeline, so feature vocabulary and inverse document frequencies are learned only from the training subset in each experiment. The fixed test split is only used for prediction and scoring.

### 3.3 Training-size experiment and metrics

The training subsets are stratified and sampled reproducibly with random seed 42. Each is evaluated against all 25,000 official test reviews. Precision, recall, and F1 are reported for the positive class; accuracy is also reported. Fit time measures pipeline fitting and excludes dataset loading and test-set prediction. The measured values are generated by `python -m src.train` and stored in `metrics.csv` and `metrics.json`.

## 4. Results

| Training reviews | Test reviews | Accuracy | Precision | Recall | F1 | Fit time (s) |
|---:|---:|---:|---:|---:|---:|---:|
| 1,000 | 25,000 | 0.8338 | 0.8304 | 0.8390 | 0.8347 | 0.83 |
| 5,000 | 25,000 | 0.8676 | 0.8623 | 0.8750 | 0.8686 | 5.24 |
| 25,000 | 25,000 | 0.8893 | 0.8913 | 0.8867 | 0.8890 | 20.39 |

For the full-data model, negative-review precision, recall, and F1 are 0.8873, 0.8918, and 0.8896. Positive-review precision, recall, and F1 are 0.8913, 0.8867, and 0.8890. Overall accuracy is 0.8893 (22,232 correct predictions out of 25,000). The confusion matrix is saved as `figures/confusion_matrix.png`; the full class-wise report is in `classification_report.txt`.

## 5. Discussion

The results show a consistent improvement as more labeled training examples are supplied: accuracy rises by 5.54 percentage points between the 1,000-review and 25,000-review conditions. The 5,000-review model already reaches 86.76% accuracy, while the full training split reaches 88.93%. Precision and recall remain similar for the two classes, indicating that the model does not obtain its overall score by favoring only one sentiment label. The experiment demonstrates the requested small-to-large data progression using a fixed evaluation set.

## 6. Limitations and future work

The evaluation covers only English movie reviews from one benchmark domain. Reviews may contain sarcasm, mixed opinions, or contextual references that a bag-of-words model cannot represent well. The experiment compares training-set sizes but does not perform hyperparameter search, repeated random seeds, confidence-interval estimation, or a comparison against neural or pretrained transformer models. Fit times depend on the local machine. Future work could add cross-validation on training data, error analysis, calibration, and cross-domain tests while keeping the official test set untouched until final evaluation.

## 7. Reproducibility and use

From the project directory, install `requirements.txt`, then run `python -m src.train`. This downloads the dataset if needed and creates the metrics, fitted full-data pipeline, class report, and confusion-matrix figure in `results/`. A new review can be classified with `python -m src.predict "review text"`. The upstream repository is https://github.com/MubeenAhmed23/imdb-sentiments. The report and generated artifacts are included with the project sources.
